# First Five Minutes

**Your CI is green. Can a newcomer run your project?**

First Five Minutes is a proposed terminal-first eve agent for maintainers. Pick a reviewed revision, describe one useful outcome, and approve how to check it. The agent follows the quickstart as written. You get a Markdown report showing what worked, where it stopped, and which changes (if any) survived an independent replay.

**Status: design and research only.** There is no runnable CLI, measured sandbox result, or DevNet verdict yet. Five minutes is a lens on onboarding, not a pass/fail deadline.
